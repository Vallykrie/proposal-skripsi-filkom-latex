# Template Proposal Skripsi FILKOM UB (LaTeX)

Template LaTeX publik dan **tidak resmi** untuk proposal skripsi Fakultas
Ilmu Komputer Universitas Brawijaya (FILKOM UB).

> Proyek ini tidak diterbitkan, disahkan, atau didukung oleh FILKOM UB.
> Panduan resmi FILKOM dan arahan dosen pembimbing selalu menjadi acuan
> utama.

Versi awal sedang dibangun berdasarkan Panduan Skripsi FILKOM versi 3.0.
Dokumentasi penggunaan lengkap akan mengikuti fitur yang sudah diverifikasi.

## Lisensi

Kode dan dokumentasi dirilis dengan LPPL 1.3c. Logo institusi dikecualikan
dan dijelaskan secara terpisah dalam `assets/NOTICE.md`.
