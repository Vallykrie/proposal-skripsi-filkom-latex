# Contoh Minimal

Repo utama sendiri adalah contoh yang dapat dikompilasi. Untuk memulai dokumen
baru tanpa merusak class:

1. Salin seluruh repositori.
2. Pertahankan `filkomproposal.cls`, `proposal.tex`, direktori `bibliography/`,
   `assets/`, dan skrip build.
3. Ubah hanya `metadata.tex`, ketiga berkas dalam `chapters/`, dan
   `bibliography/references.bib`.
4. Hapus isi contoh lampiran atau daftar istilah jika tidak digunakan, tetapi
   pertahankan berkasnya agar entry point tetap sederhana.
5. Jalankan `make preview`, kemudian `make official` sebelum pengumpulan.

Contoh sengaja tidak diduplikasi sebagai proyek kedua agar pembaruan format dan
perbaikan bug hanya memiliki satu sumber kebenaran.
